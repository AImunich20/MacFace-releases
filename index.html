Not as secure as Face ID or Touch ID

ไม่ปลอดภัยเท่า Face ID หรือ Touch ID

  • A Mac webcam sees a flat 2D image, with no depth sensor.
  • It stops printed photos and phone screens reasonably well (strict liveness on), but not reliably a video of you.
  • MacFace unlocks by typing your stored password on the lock screen. It is a convenience, not a security upgrade.
  • กล้อง Mac เห็นภาพ 2 มิติ ไม่มีเซนเซอร์วัดความลึก
  • กันรูปที่พิมพ์และรูปบนจอมือถือได้ระดับหนึ่ง (เมื่อเปิด liveness แบบเข้ม) แต่กันวิดีโอของคุณได้ไม่แน่นอน
  • MacFace ปลดล็อกโดยพิมพ์รหัสผ่านที่เก็บไว้ให้บนหน้าจอล็อก ช่วยให้สะดวกขึ้น ไม่ได้ปลอดภัยขึ้น

Install

วิธีติดตั้ง

  1. Open MacFace.dmg and drag MacFace into Applications.
  2. If macOS says it can't be opened: System Settings → Privacy & Security → Open Anyway (once only).
  3. Follow the setup: allow Camera and Accessibility, enroll your face, then enter your Mac password.
  1. เปิด MacFace.dmg แล้วลาก MacFace ไปไว้ใน Applications
  2. ถ้า macOS แจ้งว่าเปิดไม่ได้: ไปที่ System Settings → Privacy & Security → Open Anyway (ทำครั้งเดียว)
  3. ทำตามขั้นตอนตั้งค่า: อนุญาต Camera และ Accessibility ลงทะเบียนใบหน้า แล้วใส่รหัสผ่าน Mac
